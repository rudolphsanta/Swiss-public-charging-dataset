The data in this repository include historical statuses of public charging infrastructure in Switzerland between December 2022 and December 2025. 
The real-time status information and source of these data can be found here:  https://opendata.swiss/de/dataset/ladestationen-fuer-elektroautos
The real-time data was queried and recorded in 5-minute intervals over the 3-year time horizon, and are saved in monthly compressed .parquet files. The charging load over this period is also estimated and provided in .csv files.

Please review the forthcoming publications for further details on the data contained in this repository.
